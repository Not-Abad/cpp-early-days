##  ¿Qué contiene este repositorio?

Este espacio funciona como un archivo personal que almacena los scripts iniciales escritos en **C++** durante mis primeras clases de programación. Incluye:

* Ejercicios de sintaxis básica y manejo de variables.
* Implementación de estructuras de control (condicionales y bucles).
* Prácticas de lógica y resolución de problemas algorítmicos elementales.
* Experimentación de la funcion de desplazamiento del cursor GOTOXY.
